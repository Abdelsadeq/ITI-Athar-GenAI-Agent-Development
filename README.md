# ITI Athar Initiative | Generative AI & Agent Development

Welcome to my GitHub repository for the **Generative AI & Agent Development** track of the **Athar Initiative**, organized by the Information Technology Institute (ITI) in collaboration with the Egyptian Ministry of Higher Education and Scientific Research.

This repository contains my weekly assignments, practical exercises, and hands-on projects completed throughout the training program.

## About the Initiative

The Athar Initiative aims to support university faculty members and teaching assistants in developing practical technology skills, encouraging innovation, and applying modern technologies in education and research.

## Training Track

**Generative AI & Agent Development**

The track focuses on understanding Generative AI technologies, working with APIs and language models, and developing practical AI-powered applications.

## Weekly Assignments

Each assignment is organized in a separate folder to keep projects independent, easy to review, and simple to maintain.

| Week | Assignment | Description |
|---|---|---|
| 01 | [Working with a Public REST API Using Python](Week-01-REST-API/) | Building a Python application using a public weather API, JSON parsing, custom classes, and secure environment variables. |
| 02 | [Generative AI in Your Department](Week-02-GenAI-Academic-Advising/) | Exploring an AI-powered academic advising assistant for course registration, GPA monitoring, and graduation planning, including risks and data privacy. |
| 03 | [Your First API Call](Week-03-First-API-Call/) | Connecting to OpenAI and Gemini APIs, generating responses, tracking token usage, calculating estimated costs, and comparing models. |

*This table will be updated as new assignments are completed.*

## Skills and Technologies

The assignments provide practical experience in:

- Python programming and REST API integration.
- JSON data processing and object-oriented programming.
- Generative AI applications in education.
- Prompt engineering and language model APIs.
- Token usage monitoring and API cost estimation.
- Secure API key management using environment variables.
- Git and GitHub for project organization and version control.

## Assignment Documentation

Depending on the requirements, each assignment folder may contain:

- Python source code and project files.
- A dedicated README with setup instructions.
- Required dependencies and configuration examples.
- Reports or PDF submissions.
- Sample outputs and execution screenshots.

**Security:** API keys, `.env` files, and virtual environments are excluded from version control. No sensitive credentials should be uploaded to GitHub.
